# 小说创作任务

- [x] 小说创作入口和项目创建
  - Acceptance: 可创建 `type=novel` 的项目并在 `/novel` 可见。
  - Verify: 前端构建与浏览器验证。
- [x] 小说章节与影视转换
  - Acceptance: 创建/编辑章节并从章节进入项目剧本和画布流程。
  - Verify: API、UI 和画布链接验证。
- [x] 审稿记录、记忆、版本回溯和分支候选基础
  - Acceptance: 所有记录与当前用户、小说项目和章节绑定；恢复版本只改当前章节。
  - Verify: Go 编译、迁移专项测试、前端类型检查和生产构建。
- [x] 章节到剧本场次基础
  - Acceptance: 小说章节可创建原生场次，并关联当前小说项目中的角色资产。
  - Verify: 迁移专项测试与服务/路由编译通过。
- [x] 场次到镜头来源链接基础
  - Acceptance: 从场次创建既有镜头时，保存场次 ID 与来源哈希；镜头版本保留原始场次引用。
  - Verify: 迁移专项测试、Go 编译、前端类型检查和生产构建。
- [ ] 角色/场景资产与视频生产来源关联
  - Acceptance: 小说角色/场景可映射为现有项目资产，视频任务能回溯章节、场景和镜头来源。
  - Verify: API、分镜任务与画布链接回归测试。
